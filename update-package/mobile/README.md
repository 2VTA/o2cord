# o2cord Mobile

The o2cord bundle for Discord on iPhone / Android, built from Kettu (BSD-3-Clause,
https://codeberg.org/cocobo1/Kettu) with o2cord's changes:

- o2cord's own built-in plugins only, each with an on/off switch - nothing is
  installed from links, no third-party plugin code ever runs.
- "debug o2" only on Ryder's account.
- o2cord badges, RetroTerminal (o2cord crew).

Load it with a Kettu loader that supports a custom URL:
https://raw.githubusercontent.com/2VTA/o2cord/main/update-package/mobile/o2cord.js
